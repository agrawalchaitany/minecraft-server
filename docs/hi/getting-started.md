# <img src="../assets/icons/start.svg" width="28" height="28" alt=""> शुरुआत करें

यह गाइड आपको लगभग पाँच मिनट में शून्य से एक चलते हुए Minecraft सर्वर तक ले जाती है, जिससे आप जुड़ सकें।

## आपको क्या मिलता है

`make up` चलाने पर दो कंटेनर शुरू होते हैं:

- **`mc`**: एक [Paper](https://papermc.io) Minecraft: Java Edition सर्वर। Paper आधिकारिक सर्वर का तेज़ और प्लगइन-सक्षम विकल्प है, जिसे सीधे उसकी जगह इस्तेमाल किया जा सकता है।
- **`backup`**: एक छोटा साथी कंटेनर जो हर घंटे आपकी दुनिया का बैकअप लेता है।

सर्वर क्रैश के बाद खुद फिर से शुरू होता है, रोकने पर दुनिया को सही तरीके से सेव करता है, और ऐसी सेटिंग्स को मना कर देता है जो उसे खराब कर सकती हैं। रोज़ चलाने के लिए Docker जानना ज़रूरी नहीं; सब कुछ एक `make` कमांड है।

## ज़रूरतें

| | |
|---|---|
| Docker | Docker Desktop (macOS, Windows), या Compose plugin के साथ Docker Engine 24+ (Linux) |
| `make` | macOS और ज़्यादातर Linux डिस्ट्रीब्यूशन में पहले से इंस्टॉल |
| मेमोरी | डिफ़ॉल्ट सेटिंग्स के लिए लगभग 3 GB खाली |
| नेटवर्क | सेटअप के दौरान Paper, Java और प्लगइन्स डाउनलोड करने के लिए इंटरनेट |

## सेटअप

**1. अपनी सेटिंग्स फ़ाइल बनाएँ।**

```bash
cp .env.example .env
```

**2. `.env` में दो मान बदलें।**

```env
EULA=TRUE
MC_VERSION=latest
```

- `EULA=TRUE` का मतलब है कि आप [Minecraft EULA](https://aka.ms/MinecraftEULA) स्वीकार करते हैं। इसके बिना सर्वर शुरू नहीं होगा।
- `RCON_PASSWORD` वैकल्पिक है। इसका उपयोग अंदर ही अंदर, बैकअप और बंद होते समय दुनिया को सुरक्षित रूप से सेव करने के लिए होता है। खाली छोड़ें तो एक रैंडम पासवर्ड बनकर डेटा वॉल्यूम में रखा जाता है। यह Docker के बाहर कभी उजागर नहीं होता।
- `MC_VERSION` वह Minecraft संस्करण है जिसे चलाना है। `latest` रखें, या `make versions` से कोई चुनें, जैसे `1.21.4`। **अभी चुनें:** दुनिया को बाद में नए संस्करण पर अपग्रेड किया जा सकता है, लेकिन पुराने पर कभी वापस नहीं लाया जा सकता। देखें [Minecraft संस्करण](minecraft-versions.md)।

**3. शुरू करें।**

```bash
make up
```

पहली बार चलाने पर Java और Paper डाउनलोड होते हैं और इमेज बनती है, जिसमें कुछ मिनट लगते हैं। आपको दिखेगा कि कौन-सा संस्करण चुना गया:

```
==> Minecraft 26.3 (Paper) on Java 25
```

**4. healthy होने तक इंतज़ार करें।**

```bash
make status
```

जब `mc` कंटेनर `(healthy)` दिखाए, सर्वर तैयार है। शुरू होते हुए देखने के लिए `make logs` चलाएँ, और देखना बंद करने के लिए <kbd>Ctrl</kbd>+<kbd>C</kbd> दबाएँ। इससे सर्वर बंद नहीं होता।

## जुड़ें

Minecraft में **Multiplayer → Add Server** चुनें और डालें:

- `localhost`, अगर सर्वर उसी कंप्यूटर पर चल रहा है, या
- सर्वर का IP पता, अगर वह कहीं और चल रहा है। क्लाउड सर्वर पर पोर्ट 25565 भी खोलें; देखें [डिप्लॉयमेंट](deployment.md)।

## खुद को ऑपरेटर बनाएँ

```bash
make cmd C="op YourMinecraftName"
```

## बाद में सेटिंग्स बदलना

`.env` बदलें, फिर चलाएँ:

```bash
make up
```

`make up` नई सेटिंग्स लागू करता है और आपकी दुनिया बनाए रखता है। (`make restart` केवल *पुरानी* सेटिंग्स के साथ फिर से शुरू करता है।)
